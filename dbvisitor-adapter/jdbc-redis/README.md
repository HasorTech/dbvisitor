# jdbc-redis

通过 JDBC 接口和 Redis 命令访问 Redis，连接 URL 使用 `jedis` 前缀。完整文档统一维护在 `dbvisitor-doc`。

Access Redis through JDBC and Redis commands, using the `jedis` URL prefix. Full documentation is maintained in `dbvisitor-doc`.
